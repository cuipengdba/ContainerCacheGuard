# rc.14 / rc.15 开发与验收计划

日期：2026-11-11；C034：用户要求规划两个版本，并在规划后直接开发、测试、推送GitHub。两版独立提交、原生amd64/arm64验证；构建静态候选，保持现有配置兼容。171和94运行环境本轮不连接、不修改，已有现场问题和48小时验收不计通过。

| 版本 | 优化内容 | 验收依据 |
| --- | --- | --- |
| 0.2.0-rc.14 | 统一有界普通文件信号读取；拒绝符号链接、FIFO、过大输入、重复JSON字段和过深嵌套；兼容业务信号附加字段 | 异常输入拒绝、读取不挂起、已有有效格式不变；真实临时文件回归通过 |
| rc.14 | 新增check-config离线检查；状态/日志/doctor显示信号有效性、年龄、剩余有效期、节点停止线和余量 | 不触碰PGDATA或cgroup；缺失不是0；保护输入展示与是否允许回收分开 |
| rc.14 | 释放许可按指标与外部信号共同的最早有效期收回 | 即使采集和日志有耗时也不继续使用过期许可；原恢复窗口不能被绕过 |
| 0.2.0-rc.15 | 离线小时统计增加普通文件缓存时间积分、有效覆盖秒数、业务p99采样最大值 | 仅连续、同运行/身份、有效样本衔接；按小时分割，不填补空窗，不把匿名/共享内存当可回收文件页 |
| rc.15 | 新增compare，对两份报告按实例分别比较峰值、时间加权平均、自身开销及尾延迟采样指标 | 新schema、身份和覆盖检查，基线observe、候选enforce；缺证据返回明确的不足状态，不输出生产验收通过 |
| rc.15 | 可配置比较阈值与完整中文对比手册、四角色说明 | 无额外守护线程、Web或后台扫描；CLI与非有限值/异常报告回归 |

不在本轮新增强制清理匿名内存、全局drop_caches、任意命令执行、自动杀备份或业务、内核/cgroup修改、PG升级和自动现场部署。受限输出仍是实验功能。compare只评价报告中的候选遥测门槛：全备耗时、校验恢复、等压数据和K8s事件必须由独立试验补足，不能将“报告可比较”称为“不会驱逐”。

每版完成后记录实际提交、CI、通过/失败和发布地址；本表是计划，不是测试结论。
