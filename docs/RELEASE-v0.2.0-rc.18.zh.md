# ContainerCacheGuard 0.2.0-rc.18 候选版

本版针对“PostgreSQL与备份继续在同一容器”增加统一预算下的路径角色和任务感知。DBS、HISDBS每个容器各运行一个CCG，不再要求拆备份容器。原PG14、DBS调度和备份参数保持由原环境管理；本版没有在171或94部署。

## 新增与改进

- `path_policies`区分数据库源、备份输出、排除目录；源端保护至少60秒，全部路径共享原总预算；输出有界优先并保留普通轮询机会。
- 目录身份绑定/重验、工作索引内inode去重与角色冲突拒绝；输出硬链接拒绝，不声称完成全量别名审计。覆盖和候选事件带角色。
- 可选`task-run`包装原前台任务；参数、流、退出码和信号传递，多个任务独立有界心跳；verify/压缩/传输/恢复停让相关文件新建议，未知状态暂停，任务ID不重置内核压力事件。
- 可选静态二进制`node-collect`复用认证kubectl采集有效配置、原始node/allocatable内存信号及实际块设备区间指标；不猜默认、不跳过TLS、不写盘标定。业务采样只消费已有真实来源。
- 逐路径无PSI输出实验资格需真实盘设备集合和新鲜业务覆盖；PGDATA继续strict，无PSI内核配置也新增设备绑定必填。
- 同优先级内核目标结合等待年龄与风险排序；不改变单次、串行、持久去重、UNKNOWN及历史OOM保护。
- 周期日志引用内核episode，完整快照仍在状态/journal/agent事件；每天一个日志、30天/1GB与无Web约定保留。

## 使用与兼容

[完整中文使用、参数、同容器接入和回退](RC18-USAGE.zh.md)。普通旧配置保持兼容，新增字段默认不开；旧`no-psi-guarded`实验配置须填写`disk_devices`，漏填拒绝，不静默放宽。节点采集当前版本适配范围v1.24—v1.31，其他版本保守拒绝；逐发行版需实测。此可选子命令需要节点既有kubectl，常驻文件后端无此依赖。PG客户端沿用原环境。

## 测试与未完成边界

最终原生CI、回收量/耗时/持续性、IO、SQL/API和同容器备份恢复结果追加在本Release附件TEST-RESULTS.json及发行说明。没有完成前不将构建成功当作验收。

下列仍未完成：真实DBS/HISDBS数据与等压对照、真实kubelet/无PSI共享盘端到端资格、较大内核请求/4GiB池、业务低影响SLO、48小时驱逐验证、ARM64 64KiB页验证。内核功能默认关闭，limited-output仍实验。文件/内核请求量不等于净收益，容器file下降不等于kubelet驱逐余量同量改善；不承诺回收anon/shmem/slab或永不驱逐。

规划中的PG只读自动进度适配本版未交付，任务阶段通过明确包装接入；没有为追求范围放开路径、OOM或缺失信号保护。下一步现场实施仍需安排，不因发布候选自动替换已有容器。
