# ContainerCacheGuard 0.2.0-rc.12

2026-11-11。基于rc.11，保留静态amd64/arm64、无Web、详细中文日志、一天一文件/30天/1GB和保护输入缺失暂停。

- doctor增加--require-ready双样本严格部署预检与中文能力原因，区分PSI权限、无效内容、可见接口缺失和明确关闭启动参数。不修改内核、不关闭保护。
- 已等待重扫的文件索引跨时间片累计一轮最早唤醒时间，全量等待期间跳过反复索引遍历；新文件/已发现身份变化使缓存失效。新增发现历时、调度与跳过原因计数。
- 重复无即时净下降的区域按1/2/4/8倍冷却退避，三次后保留有界历史再等待；再次驻留和所有原保护仍优先。
- 新增report离线小时JSON/Markdown统计，无HTTP，不访问PGDATA或cgroup。区分观察、暂停、缺样、重启、回退、建议量、复查下降和重新驻留，拒绝不完整/超限日志及特殊文件。
- 增加四角色observe模板、详细参数、预检/持久挂载/输出端与源端验证说明。

使用与边界见[rc.12手册](RC12-USAGE.zh.md)。回归、微基准与发布附件核验见[交付记录](RC12-DELIVERY.zh.md)。程序回归不代表实际数据库压力验收，索引等待微基准不代表完整扫描/磁盘IO成本。没有启用94 PSI或替换运行实例，没有操作171；PG14真实业务48小时、YsP正式服务和ARM64 64KiB页验收仍未完成。
