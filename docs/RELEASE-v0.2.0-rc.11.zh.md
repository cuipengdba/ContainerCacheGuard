# v0.2.0-rc.11：取消Web服务，提供详细日志

按用户最新需求，取消整个内置Web服务：移除页面、HTTP API、Prometheus、healthz/readyz，不再监听端口、读取页面令牌或分配页面历史缓冲。旧Web配置和CLI开关只兼容读取并一次提示已停用；新生成配置省略这些字段，不能通过旧参数重新开启HTTP。

状态文件继续提供完整机器可读快照，新增web_service_enabled=false，不再生成web_address。详细日志保留原顶层字段，增加中文原因、INFO/WARN/ERROR、可读MiB摘要和自上次记录的扫描/建议/驻留复查/错误增量。未知摘要为null，首次/重启/计数回退不伪造增量；普通文件页差值不冒充CCG回收效果。

默认10秒完整状态，决策变化提前记录但最多每秒一条状态；生命周期和清理独立记录。每天一个文件，30天和1GB双条件清理继续保留，先删最旧历史，当天独占触顶时截断当天旧内容。文件日志和控制台同源，不逐文件输出，不增加额外目录扫描。

## 升级与回退

停止旧CCG再启动新程序，不需重启数据库。升级前将旧HTTP采集/探针切换成独立进程看护和状态文件；不得把CCG故障设置为业务数据库的重启条件。持久采集和小时图表仍需外部采集器，程序没有新增网络服务。旧运行进程不会因GitHub发布自动取消监听。

回退时恢复旧程序和旧配置，旧版不认识新日志字段；旧版本可能重新提供其原有Web服务，应按实际需要删除或关闭旧Web参数。不要把停止CCG当作已恢复被释放的缓存。

## 验证边界

本版将用原生amd64/arm64 race和CLI回归验证真实进程无TCP监听、旧参数不打开令牌FIFO、状态及详细日志、危险路径与写失败、保护缺项及恢复、内容不变和静态构建。旧网页测试已取消，不能记成新版本通过。编码微基准不等于实际日志IO或数据库影响。
